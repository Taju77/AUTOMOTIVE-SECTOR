# AUTOMOTIVE-SECTOR #

In this repository I will post the Data Sources that I have used in order to have a deeper knowledge about Statistics related with the Automotive Sector. Variables of interest within this field include:

- **Automobile Production Statistics**
- **Sales Registrations Statistics**
- **Exports and Imports of Finished Vehicles and their Parts and Components (P&Cs)**
- **Total Vehicle Fleet**

Also, I will include all the different Data Sources and their links in an Excel at the top of the folders. All these Data Sources have taken part in helping me develop a research project inside the Big Data Project and inside the Master in Quantitative Economic Analysis (MQuEA) 
at Universidad Autonoma de Madrid (UAM) as a further version for development for my Master's Thesis (TFM).

This research project bears all the different Data Sources with which I have constructed the sections of my work:

1: Descriptive Statistics: Facts & Figures 
2: Geographical Breakdown and LEZs
3: Predictive Analysis: Bass Diffusion Technology Model
